# Updating M12 → M13 (audit fixes)

1. Read `docs/AUDIT_REPORT.md` and `docs/deployment.md`. The audit is not production certification; auth, real RTSP/GPU, container runtime and 24/7 target checks remain gates.
2. Back up PostgreSQL, Redis persistence/config, snapshots/uploads and your private `.env`. Prefer a quiescent point after both Streams drain. Restore-test backups before destructive operations. Never downgrade a real database merely to repeat audit tests.
3. Keep the complete existing Git history. This release descends from M12 `ac41f76`; do not run `git init`. The release archive contains real `.git` and the manifest-verified model weights.
4. Install frozen Python dependencies (`uv sync --frozen`) and frontend dependencies (`npm --prefix frontend ci`) with supported Node `^22.22.2 || >=24.15.0`. Security floors: certifi >=2026.10.19, Pillow >=13.0.0. No other model/backend/runtime replacement is implied.
5. M13 has **no new database migration**. The required head remains `b6b7cfcd87c5`; check/upgrade normally if starting from an older release. The camera quota uses a transaction advisory lock and is safe across API processes running this version; do not mix old writers that bypass the lock.
6. Restart API/worker/frontend together. API adds an early upload-envelope guard; CSV keeps the same schema and all-or-nothing contract but reads rows in bounded batches and allows two concurrent jobs per API process. Busy export returns 503/retry.
7. Snapshot buffering changes from 4 jobs to a bounded 32 jobs/128 MiB raw-frame reservation budget. Monitor the new snapshot metrics and memory/disk; a full queue still publishes alarms without images. This is not a promise of arbitrary-burst capacity.
8. Compose now binds all published ports to loopback. Use a deliberate authenticated TLS gateway for remote operator access, not unprotected public ports. New images prepare UID10001 snapshot directories; check old volumes separately. Nginx default upload request cap is 2049 MiB; keep it aligned with API settings and disk quotas.
9. Validate readiness, a camera start/stop, event history, a JPEG, CSV, analytics, metrics, and both Streams after restart. Review warnings and monitoring; retain the M12 archive for comparison. Rolling back binaries or dependencies must not discard new data or restore known-vulnerable packages without an explicit recovery plan.
