# ADR-014. Состояния человека

Статус: принято (Milestone 1)

`PersonState` = `NORMAL`, `IN_DANGER_ZONE`, `LOST`. `CROSSING_LINE` из §20 не вводится: пересечение мгновенно, и это событие, а не состояние. Детализация входа/выхода (`ENTERING`, `EXITING`) — внутренний автомат пары трек–зона, наружу не отдаётся.

**Почему:** Меньше состояний (§20) и никаких состояний длиной в один кадр.
