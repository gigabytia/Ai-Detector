# ADR-016. Mock-режим

Статус: принято (Milestone 1)

Mock-камера (`mock://{scenario}`) рисует синтетические кадры по сценарию из `vision_worker/scenarios/` ([ADR-024](ADR-024-mock-scenarios-location.md)) (траектории людей с временами). Детекции для таких кадров даёт `scripted`-детектор по тому же сценарию; с Milestone 4 он выбирается автоматически для каждой mock-камеры ([ADR-029](ADR-029-detector-per-source.md)); глобальный переключатель не используется. Отдельный флаг `MOCK_CAMERA` не вводится. Реальная модель на синтетических кадрах людей не найдёт, поэтому для демо с настоящим детектором используется видеофайл.

**Почему:** Демо-камеры работают без физической камеры и сети; с Milestone 4 модель всё равно обязательна для запуска worker (fail-fast по ADR-029); те же сценарии используются в детерминированных тестах (§181).
