# ADR-016. Mock-режим

Статус: принято (Milestone 1)

Mock-камера (`mock://{scenario}`) рисует синтетические кадры по сценарию из `tests/fixtures/scenarios/` (траектории людей с временами). Детекции для таких кадров даёт `scripted`-детектор по тому же сценарию; он выбирается глобально (`DETECTOR_BACKEND=scripted`). Отдельный флаг `MOCK_CAMERA` не вводится. Реальная модель на синтетических кадрах людей не найдёт, поэтому для демо с настоящим детектором используется видеофайл.

**Почему:** Проект запускается без камеры, модели и сети; те же сценарии используются в детерминированных тестах (§181).
