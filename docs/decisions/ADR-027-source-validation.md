# ADR-027. Проверка источника при добавлении камеры

Статус: принято (Milestone 3)

При создании и изменении камеры API проверяет только то, что можно проверить сразу и надёжно:

* формат URL для типа (`rtsp://`/`rtsps://` с хостом; `upload://<32 hex>.<ext>`; `mock://<имя>`);
* для `file` — что загруженный файл существует в `UPLOAD_PATH`.

Отдельной кнопки «Проверить подключение» в MVP нет. RTSP проверяется при запуске: статус «Подключение…» → «В работе» или «Недоступна» с временем последней попытки появляется в UI в течение 1–2 с. Проверка из API потребовала бы сетевого доступа API к камерам и дублировала бы код worker'а.

**Почему:** простейший вариант, который даёт оператору тот же ответ — работает камера или нет.
