# ADR-007. Статусы события

Статус: принято (Milestone 1)

§0.3 задаёт `NEW → ACKNOWLEDGED | FALSE_POSITIVE`, §40 дополнительно перечисляет `RESOLVED`, но не описывает, когда он наступает. В MVP три статуса; `RESOLVED` не вводится. Колонка `status` — text с CHECK, добавление статуса — одна миграция.

**Почему:** Не создаём статус без сценария использования (§174).
