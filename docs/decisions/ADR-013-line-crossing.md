# ADR-013. Пересечение линии

Статус: принято (Milestone 1)

Сторона определяется по знаку векторного произведения с полосой нечувствительности `LINE_HYSTERESIS` (нормализованное расстояние до прямой). Дополнительно требуется, чтобы проекция anchor в момент смены стороны лежала на отрезке P1–P2: ТЗ задаёт линию двумя точками, и проход по её продолжению пересечением не считается. Расстояние считается в нормализованных координатах, поэтому полоса немного анизотропна при 16:9 — при пороге 0,01 это незаметно.

**Почему:** Минимальная логика, которая убирает дребезг и ложные срабатывания на продолжении линии.
