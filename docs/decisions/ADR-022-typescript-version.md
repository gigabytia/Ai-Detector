# ADR-022. Версия TypeScript

Статус: принято (Milestone 2)

На дату Milestone 2 последняя версия TypeScript — 7.0, но `typescript-eslint` поддерживает `<6.1`, а `openapi-typescript` — `^5`. Используется TypeScript `~5.9.3`, совместимый со всеми инструментами. Переход — когда инструменты объявят поддержку новой версии.

**Почему:** рабочие lint и генерация типов важнее последней версии компилятора.
