# ADR-008. Cooldown событий

Статус: принято (Milestone 1)

Default `EVENT_COOLDOWN_SECONDS = 3` из §0.3 (пример 5 с в §137 считается иллюстрацией). Ключ — камера + track + тип события (как в §0.3). Cooldown — отдельный фильтр после правил: правила уже дают одно событие на визит, cooldown подавляет повтор, если человек вышел (дольше grace) и вошёл снова быстрее чем через 3 с. Такой быстрый повторный вход считается дребезгом, а не новым событием. При нескольких зонах на камере ключ без zone_id может подавить вход во вторую зону в течение 3 с — для MVP с одной зоной в UI это допустимо.

**Почему:** Буквальное следование §0.3; конфликт с «cooldown не должен скрывать новое событие» сведён к окну 3 с.
