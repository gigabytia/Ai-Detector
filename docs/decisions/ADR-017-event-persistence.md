# ADR-017. Доставка и запись событий

Статус: принято (Milestone 1)

Worker публикует событие одновременно в pub/sub (для SSE) и в Stream (для записи). Оператор получает тревогу, даже если PostgreSQL недоступен. Если оператор меняет статус ещё не записанного события, API возвращает `409 EVENT_NOT_PERSISTED_YET`, frontend повторяет запрос. Дубли исключает UUID события, созданный worker'ом. Отдельный fingerprint не хранится: защиту дают автоматы правил, cooldown и идемпотентный ключ.

**Почему:** Для системы безопасности задержка тревоги важнее, чем гарантия, что её сразу можно подтвердить.
