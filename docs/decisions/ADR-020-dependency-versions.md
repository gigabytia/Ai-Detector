# ADR-020. Версии зависимостей

Статус: принято (Milestone 1)

В среде, где выполнялся Milestone 1, нет доступа к сети и нет `uv`. Версии библиотек на этом шаге не выбирались. В Milestone 2 версии берутся из официальной документации, если сеть есть; если нет — последние известные стабильные, фиксируются в lock-файлах и помечаются в `PROGRESS.md` как непроверенные.

**Почему:** Требование §0.7.
