# ADR-012. Файловые источники

Статус: принято (Milestone 1)

Камера типа `file` ссылается только на загруженный файл: `source_url = upload://{uuid}.{ext}`. Файл сохраняется под сгенерированным именем в `UPLOAD_PATH` (общий том API и worker'а), расширение и размер ограничены. Для разработки файл можно положить в `UPLOAD_PATH` вручную. Абсолютные пути и `..` не принимаются. RTSP-URL принимаются только со схемой `rtsp`/`rtsps`.

**Почему:** Закрывает обход файловой системы (§115) без отдельной таблицы загрузок.
