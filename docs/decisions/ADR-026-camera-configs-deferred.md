# ADR-026. Таблица camera_configs создаётся в Milestone 4

Статус: принято (Milestone 3)

В [database.md](../database.md) описана `camera_configs` (target_fps, пороги, cooldown…). В Milestone 3 ни одно из этих полей ещё не используется: детектора, трекинга и событий нет. Таблица и API настроек камеры появляются вместе с первым используемым полем (`target_fps`, `detection_confidence` — Milestone 4); остальные колонки — миграциями соответствующих этапов.

**Почему:** не хранить настройки, которые ничего не меняют, и не обещать их в UI.
