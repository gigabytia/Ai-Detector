# ADR-024. Где лежат сценарии mock-камер

Статус: принято (Milestone 3). Уточняет [ADR-016](ADR-016-mock-mode.md).

ADR-016 помещал сценарии в `tests/fixtures/scenarios/`. Но mock-камеру можно добавить из UI в обычном запуске, а каталог `tests` не входит в образ worker'а. Поэтому сценарии — ресурсы пакета: `vision-worker/src/vision_worker/scenarios/{name}.json`, загрузка через `importlib.resources`. Тесты используют те же файлы.

* Имя сценария — `^[a-z0-9][a-z0-9_-]{0,63}$`, поэтому `mock://../x` не выходит за пределы пакета.
* Формат: размер кадра, fps, длительность цикла, люди с ключевыми кадрами `(t, bbox)` в нормированных координатах; между ключевыми кадрами — линейная интерполяция, вне диапазона человека нет.
* В комплекте: `walk_through` (один человек проходит слева направо) и `two_people`.

**Почему:** демо без камеры должно работать и в Docker, а не только в тестах.
