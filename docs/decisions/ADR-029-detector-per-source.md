# ADR-029. Детектор по типу источника и fail-fast загрузка модели

Статус: принято (Milestone 4).

Worker до запуска HTTP загружает модель из `MODEL_MANIFEST_PATH`: проверяет SHA-256, доступность выбранного устройства, класс `person`, выполняет warmup. Нет манифеста, весов, устройства или корректного класса — CRITICAL и выход 1, без тихого fallback и автоматической загрузки из сети.

`file`/`rtsp` используют `UltralyticsPersonDetector`; `mock` — `ScriptedPersonDetector` по тому же сценарию и `source_ts_ms`, что и отрисованный кадр. Реальная модель обязательна даже для запуска только с mock-камерами: иначе проверка готовности могла бы скрыть неработающую детекцию. Глобального `DETECTOR_BACKEND` пока нет; ONNX adapter — отдельный этап. Заменяет глобальный scripted-переключатель из ADR-016.

Общий интерфейс `PersonDetector` принимает батч кадров и порог, возвращает списки боксов в пикселях исходного изображения. Библиотека Ultralytics изолирована в adapter. Манифест фиксирует модель и размер входа; AGPL-3.0 оговорена в ADR-006.
