# ADR-031. В БД только переопределения настроек камеры

Статус: принято (Milestone 4). Уточняет ADR-026.

`camera_configs`: 1:1 с камерой, nullable `target_fps` (1–30) и `detection_confidence` (>0–1). NULL означает наследование `TARGET_FPS`/`DETECTION_CONFIDENCE` из настроек API. Пока нет других реально используемых параметров, дополнительных колонок не создаём.

GET `/cameras/{id}/config` отдаёт `overrides`, `defaults`, `effective`. PUT заменяет переопределения целиком: `{}` сбрасывает всё, пропущенные поля также наследуются. Проверяются Pydantic и CHECK constraints. Первые одновременные записи сериализуются блокировкой строки камеры. После commit публикуется `camera.changed`; пропущенные уведомления компенсирует периодическая сверка worker. Worker получает только effective config в `CameraSpec` и применяет её без открытия источника заново.

Размер входа и класс модели — из манифеста, не настройки камеры. Настройки модели нельзя выдавать за параметры, которые произвольно меняют обучение или экспорт.
