# ADR-019. Запись треков

Статус: принято (Milestone 1)

`track_session` с сегментами отправляется одним сообщением, когда трек удалён, камера остановлена или worker штатно завершается. Треки, активные в момент аварийного падения worker'а, не сохраняются. Периодическая выгрузка незавершённых треков не делается до появления потребности.

**Почему:** Одна запись на трек вместо обновлений по ходу; потеря при аварии касается только аналитики, не событий.
