# ADR-023. HTTP-сервер worker'а

Статус: принято (Milestone 2)

Health-эндпоинты worker'а (а позже `/metrics` и WebSocket превью) обслуживает FastAPI + uvicorn внутри процесса worker'а; lifespan HTTP-приложения запускает и останавливает `Supervisor`. Тот же стек, что и в API, — команде не нужно учить второй фреймворк. Ограничение «без FastAPI» касается только пакета `shared`. Worker-образ не содержит пакет `app` (backend), это проверено сборкой окружения worker'а.

**Почему:** один асинхронный цикл для HTTP и Redis, без отдельного сервера.
