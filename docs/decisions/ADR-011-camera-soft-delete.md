# ADR-011. Удаление камеры

Статус: принято (Milestone 1)

`DELETE /cameras/{id}` выставляет `deleted_at` и `enabled=false`, worker останавливает камеру. История событий и аналитика сохраняются. Имя уникально среди не удалённых камер.

**Почему:** Аудит событий (§157) не должен пропадать вместе с камерой.
