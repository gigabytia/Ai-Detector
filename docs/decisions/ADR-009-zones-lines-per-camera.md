# ADR-009. Количество зон и линий

Статус: принято (Milestone 1)

Схема БД и движок правил поддерживают несколько зон и линий на камеру (1:N). Редактор в UI на Уровне 1–2 редактирует одну зону и одну линию на камеру; несколько — после MVP без изменения схемы.

**Почему:** 1:N в схеме ничего не стоит, а UI для нескольких фигур заметно сложнее.
