# ADR-015. Snapshot события

Статус: принято (Milestone 1)

Снимок — полный кадр без нарисованных рамок, JPEG кодируется в пуле потоков, после записи в `SnapshotStorage` событие публикуется вместе с метаданными снимка одним ingest-сообщением. Задержка доставки события растёт на время кодирования (~10–30 мс), зато событие и снимок пишутся одной транзакцией. Ошибка сохранения не блокирует событие. `LocalSnapshotStorage` лежит в `shared` (только stdlib), т.к. пишет worker, а читает и чистит API.

**Почему:** Нет гонки «событие без снимка → снимок позже», inference не ждёт.
