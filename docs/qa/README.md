# Проверка UI Milestone 4

Локальный Chromium (Playwright), API + worker с настоящей CPU-моделью и двумя mock-камерами. Скриншоты — свидетельство smoke-проверки, не мокапы.

* `monitoring.png`: YOLO person-боксы и две сценарные камеры одновременно.
* `focus.png`: крупный просмотр, настройки FPS/порога, подтверждение сохранения.
* `mobile.png`, `mobile-dark.png`: ширина 390px, без горизонтального overflow.

Реальный файл сделан из официального тестового изображения Ultralytics bus.jpg. Он проверяет путь file → inference → WebSocket → canvas, не точность на движущихся CCTV-данных. Некоторые скриншоты сняты во время краткой смены темы/уведомлений. Все команды и результаты — в PROGRESS.md.
