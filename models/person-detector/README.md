# Person detector

Манифест `manifest.yaml` фиксирует YOLO26 nano, класс `person` (COCO id 0), вход 640, официальный URL весов и SHA-256. Веса загружаются явно: `uv run ai-detector-model` (или `make model`). Сеть при запуске worker не используется. Существующие корректные веса можно оставить; команда повторной загрузки заменяет их только после успешной проверки временного файла.

Восстановленный архив поставляется с проверенным `yolo26n.pt` для быстрого запуска; файл по-прежнему исключён из Git. Контрольная сумма проверяется worker при каждом запуске. Веса и Ultralytics распространяются по AGPL-3.0: https://github.com/ultralytics/ultralytics/blob/main/LICENSE. Для коммерческого внедрения необходимо проверить требования AGPL либо отдельную лицензию Ultralytics. Настоящие люди детектируются только на реальных изображениях; нарисованные демо-сцены используют отдельный scripted adapter.
